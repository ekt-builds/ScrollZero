Privacy Policy

Package: com.scrollzero.blocker  •  Effective Date: November 2026

1. Core Privacy Principle: Zero Network Access

ScrollZero (com.scrollzero.blocker) is built as a strictly offline, local-only Android utility. The application does not declare the android.permission.INTERNET permission in its AndroidManifest, meaning it is technically incapable of transmitting data over Wi-Fi or mobile data.

  • No user accounts, sign-ups, or logins.
  • No analytics, crash-reporting SDKs, ad networks, or third-party trackers.
  • No external servers, cloud backups, or telemetry uploads.

2. How the Android AccessibilityService API Is Used

To detect and exit short-form video feeds automatically, ScrollZero requires explicit user activation of Android's AccessibilityService API. ScrollZero is a digital-wellbeing and focus utility—not an assistive tool for users with disabilities.

What it inspects in real time: Window state changes and basic UI hierarchy/tab identifiers exclusively within supported target apps (YouTube, Instagram, Facebook, and TikTok) to determine whether a short-form video feed (Shorts, Reels, or TikTok feed) is currently open.

What action it performs: When an enabled short-form feed is detected, ScrollZero triggers a local system navigation action (such as GLOBAL_ACTION_BACK) to exit the feed.

What it NEVER does: ScrollZero does not read, record, log, or store passwords, keystrokes, private messages, photos, browsing history, or screen contents. All UI checks occur ephemerally in device RAM and are discarded immediately.

3. Local On-Device Storage

ScrollZero stores only minimal configuration settings locally on your device (such as whether the master shield is active or paused, and which individual platforms are toggled on or off). These preferences remain inside the app's private Android sandbox and are completely removed if you clear app data or uninstall ScrollZero.

4. Third-Party Services & Links

The ScrollZero Android app itself contains no third-party SDKs or external integrations. Its companion website and APK releases are hosted on GitHub Pages and GitHub Releases (github.com/plyostrideos/ScrollZero), which are governed by GitHub's standard privacy statement when accessed via a web browser.

5. User Control & Revoking Permissions

You remain in full control of ScrollZero at all times:

  • Pause or resume blocking anytime from inside the ScrollZero app.
  • Revoke Accessibility permission anytime via Android Settings → Accessibility → ScrollZero.
  • Uninstall the app at any time to remove all local settings completely.

6. Contact & Updates

If this privacy policy is updated for future versions of ScrollZero, the revised policy will be posted on this page with an updated effective date. For questions, bug reports, or verification requests, open an issue on the project repository at github.com/plyostrideos/ScrollZero.
